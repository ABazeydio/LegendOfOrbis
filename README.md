# Legends of Orbis

Legends of Orbis(The World) is a menu-driven console RPG where players embark on an adventure through the fantasy world of Orbis.
Players create a unique character by selecting a class, and get a  random selected race, then battle various enemies in turn-based combat while collecting
equipment and progressing through increasingly difficult encounters.

## How to Run

### Run `App.java`

1. Open the project in your IDE.
2. Navigate to `src/main/java/com/bptn/individual_project/App.java`.
3. Run the `main` method.
